vibemonitor
FM1 · USB 监听推音箱
FM1 → 电脑 → 音箱
未开始
这是什么：一台"中间商"。FM1 用 USB 线连电脑后，会把自己的声音当成一路麦克风/声卡送进电脑（刷了 SLOOP 后设备名显示 Felucca，48 kHz 立体声）。本页把这路声音抓起来，转手推到你电脑正在用的音箱（比如蓝牙音箱）——这样 FM1 的声音就能跟酷我音乐一起在蓝牙上响。无啸叫风险（FM1 没麦克风）。
注意方向：USB 音频是 FM1 → 电脑，只能把 FM1 的声音送出来，不能把电脑里放的音乐灌进 FM1。想让某段音乐进 SLOOP，得把那个音频文件传进网页编辑器的采样槽（见页面下方说明）。
打开方式：本机先 python3 -m http.server 8000，再在独立 Chrome / Edge 标签页开 http://localhost:8000/fm1_monitor.html（预览框会禁麦克风/音频权限）。点"列出设备"授权后：INPUT 选 FM1，OUTPUT 选你的蓝牙音箱（留空=系统默认输出），再"开始监听"。
还是没声？两种可靠路径（任选）：① OUTPUT 下拉里选蓝牙音箱再监听（已改用 HTMLMediaElement.setSinkId，对蓝牙比 AudioContext 稳）；② 把蓝牙音箱在系统声音设置里设为默认输出，OUTPUT 留空（用系统默认）。如果下拉选了蓝牙仍不出声，多半是浏览器对该蓝牙设备的 setSinkId 失效，请走②。注意：USB 监听时 FM1 自己的喇叭也会响（USB 不会静音它），要单声源就用 3.5mm 线接音箱（插线会静音 FM1 喇叭）。
只想让蓝牙音箱响、FM1 自己别出声？（"两边一起响有点乱"就是这么来的：FM1 自带喇叭零延迟、蓝牙慢半拍，同一段音乐错开成重影）两招任选：
① 最省事：随便拿一副耳机或一个 3.5mm 插头插进 FM1 的耳机孔（不用戴）。M-VAVE 官方硬件规格写明"插耳机自动静音内置喇叭"，USB 音频不受影响，蓝牙照常响（SLOOP 文档没复述这条，属硬件行为，插上用耳朵验一下；万一没静音就走②）。
② 不想插东西：FM1 上按住 HOME 打开菜单 → SELECT 翻到 AUDIO 区 → PRESETS 把光标移到 USB AUDIO → OCT+ 切成 FULL → OCT− 关菜单 → 再把 MASTER 旋钮拧到 0。FULL 是固定满电平，这时 MASTER 只管喇叭/耳机，所以喇叭静音、USB 那路（蓝牙）照常响。顺序千万别反：默认 USB AUDIO=MASTER 时先拧 MASTER 到 0，会把蓝牙一起掐掉（误以为坏了），先设 FULL 再拧。
延迟本身去不掉（蓝牙固有），但重影没了声音就干净了；要彻底零延迟只能用 3.5mm 线接音箱（插线会静音 FM1 喇叭）。
备选：不想用网页也行——Windows 声音设置里对 FM1 输入勾"侦听此设备"并选蓝牙音箱播放；Mac 用 GarageBand 输入监听或 BlackHole 路由到蓝牙。
想把酷我音乐里某段前奏放进 SLOOP 当素材？那是另一回事，走网页编辑器：Chrome/Edge 打开 https://isod89.github.io/sloop-fm1/webapp/editor/ → 点 Connect → 进 CHOP 页，把那段前奏的音频文件（WAV/MP3/AIFF 都行，多长都可以）拖进去 → 切片段 → Fit to slot 塞进采样槽（每个槽约 7.4 秒，USR3+4 合起来约 15 秒，一槽最多 16 个片段、一键一个）→ 之后就能在 SLOOP 的白键上把它弹出来。前提是你得先有那个音频文件（酷我音乐里在线听的歌没有本地文件，得先下载/录下来）。

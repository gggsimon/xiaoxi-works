它们是怎么串起来的
FM1 / SLOOP→USB MIDI→ 01 / 03 发声音符→USB 音频→ Mac→ 02 监听页→ 蓝牙音箱
01 和 03 都是「写音符 / 发声音」的，走 USB MIDI，需要允许 MIDI 权限。
02 只负责「把机器出的声转到蓝牙」，走 USB 音频，需要允许麦克风权限。
要存进机器：03 导出 4 个单轨 .mid → SLOOP 网页编辑器逐轨 Import → SAVE。
注意：file:// 本地文件才稳；预览面板里 MIDI / 麦克风会被浏览器挡掉

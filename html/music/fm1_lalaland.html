FM1 · 自由编曲
自己写 · 载入作品 · 一键盖音色 · 直推 SLOOP
怎么用
  1. 连接：点「连接设备」→「▶ 播放」。要在独立 Chrome / Edge 标签页打开本页并允许 MIDI。
  2. 编曲：第 05 面板点空格子写音，点已有格子改音高／长短／力度。轨不够就第 02 面板「＋ 加一条轨」。
  3. 盖音色：第 06 面板点一下音色，直接盖到轨上，不用在机器里翻英文。
  4. 推出去：第 07 面板，下载 .mid 灌进机器，或开监听页走蓝牙。

02 · 音轨（想加几条加几条，最多 12 条）
声部 / 名字音色（点第 06 面板更快）通道类型八度音量开试删
加进来的轨在网页里单独写、单独换音色；机器只有 4 条轨，第 07 面板有「导出给机器的 4 个 .mid」自动叠进去。
鼓轨的鼓音符：
名字能改、通道能改、「乐器 / 鼓」点一下就切、不喜欢就删。PC 号 0 起，是 SLOOP 固件里的真实编号。网页里超过 4 条轨时，多出来的轨各走自己的通道（V16 八声部能分开响）；SLOOP 机器只有 4 条物理轨，用第 07 面板那个导出按钮折叠成一个不丢音的 4 文件包。
03 · 作品库（不会编就载入，会编就发给别人）
双向：内置作品、别人给的 .mid／.json 都能导进来接着改；自己编完导出 .json 发别人，音色、速度、节拍、音符一起带过去。导 .mid 只覆盖文件里有音符的那几条轨。
04 · 画笔 & 工具
点网格里的格子开始写
空格子＝按画笔写一个音；已有格子＝点一下选中，在上面改；按 Delete 删选中的整格。每条轨右上「清空本轨」可以整轨重来。
05 · 编曲网格（点格子就写）
左边是小节号＋和弦名，格子里是音名（K/S/H＝底鼓/军鼓/踩镲）。金色框＝选中格，播放时细金框＝当前步。载入不同作品，格子数会自动变成 12 或 16。
06 · SLOOP 音色库（点一下直接盖到轨上）
157 个内置音色 + 46 个鼓组；点鼓组自动落到鼓轨，没有鼓轨就自动加一条。
编号来自 SLOOP 固件 ui.c 的 BANK[]（0 起，PC 0 = 808 BOOM）。点中后若「推音色」开着，会立刻发 CC0=0 + PC 到设备。
07 · 推到设备 / 蓝牙 / 导出
  1. 马上听：连接 → 播放。音符实时进 SLOOP，不写进机器音序器。
  2. 存进机器：下载 4 个单轨 .mid → SLOOP 网页编辑器 → 逐轨 Import MIDI → SAVE。
  3. 只让蓝牙响：开 fm1_monitor.html（输入选 Felucca）→ FM1 上 USB AUDIO = FULL → MASTER 拧 0。顺序别反。
本页 → USB → Felucca 发声 → USB 音频 → Mac → 监听页 → 蓝牙音箱
机器上只有 4 条轨：网页里加到 5 条以上时， 「给机器的 4 个 .mid」会把多出来的声部按通道叠进 1/2/3/10，一个音都不丢，直接逐轨 Import 就用。 「逐轨 .mid」是你在网页里看到的分层，给库乐队或者刷回 V16 八声部用。
